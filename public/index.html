Setup Instructions

  1. Enter your Shopify store domain (e.g., your-shop.myshopify.com)
  2. Provide your carrier's API endpoint URL
  3. Enter your carrier's API key for authentication
  4. Enable the integration by checking the checkbox
  5. Click "Save Configuration" to activate
  6. Test the connection to ensure everything works
